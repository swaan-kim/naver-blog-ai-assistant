# AI 냠냠 4주 파일럿

이 폴더는 공개 `main`에 바로 배포하지 않는 로컬 운영 공간입니다. 기존 게시글 9편은 연결하거나 수정하지 않고, 새 목차 글과 이후 8편만 관리합니다.

## 시작 문장

```text
이번 주 AI 냠냠 시작
```

이 문장으로 후보 5개를 받은 뒤 다음 순서로 진행합니다.

```text
주제 선택 → 근거·제목·목차 → 목차 승인 → 사용 메모 → 초안
→ 문단별 수정 → 최종본 승인 → 네이버 준비 → "발행" → 링크 갱신
```

예약 실행은 사용하지 않습니다. 주제, 목차, 최종본은 매번 주인장이 승인합니다.

## 파일 원칙

- `brief.md`: 독자 질문, 출처, 제목 후보, 승인된 목차, 주인장 메모를 기록합니다.
- `draft.md`: 네이버에 넣을 최종 원고와 메타데이터만 둡니다.
- `content-index.json`: 상태, 발행 URL, 이전·다음·짝 글 관계의 단일 원본입니다.
- 원문 자료 전문, 로그인 정보, 세션 파일, 네이버 DOM은 저장하지 않습니다.

`somsom-master.png`는 기존 캐릭터 기준 자산입니다. 해시가 달라지면 표지 제작을 멈추고 원본 여부를 다시 확인합니다. `_shared/cover-template.html`은 원본 이미지를 바꾸지 않고 제목만 겹쳐 보여주는 템플릿입니다.

## 안전 게이트

- `[[확인 필요]]`가 남으면 네이버 준비와 발행을 모두 중단합니다.
- 직접 사용 후기는 사용 단계와 경험 메모 네 문장이 있어야 합니다.
- 최종본 승인 전에는 네이버 편집기에 입력하지 않습니다.
- 발행은 현재 대화에서 주인장이 정확히 `발행`이라고 요청한 경우에만 진행합니다.
- 링크 갱신에 실패해도 새 글을 다시 발행하지 않습니다.

## 파일럿 완료

8편, 허위 경험·출처 오류·오발행 0건, 새 글 내부 링크 100%, 월간 기준선 확보를 모두 확인한 뒤에만 공개 스킬과 README에 운영 결과를 반영합니다.
