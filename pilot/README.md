# AI 냠냠 4주 파일럿 v2

이 폴더는 공개 `main`에 바로 배포하지 않는 로컬 운영 공간입니다. 기존 게시글 9편은 `legacy_excluded`로 두고 연결하거나 수정하지 않으며, 새 문제별 허브와 이후 8편만 관리합니다.

브라우저 도구의 `.env`에는 이 `pilot` 폴더의 절대 경로를 `AI_NAMNYAM_PILOT_ROOT`로 지정합니다. 원고·인덱스·이미지가 이 경로 밖을 가리키면 입력 전에 중단됩니다.

처음이라면 [START-HERE.md](START-HERE.md)에서 준비된 3개 제안과 정확한 승인 문장을 먼저 확인합니다. 주제 선정 근거와 모의 독자·이미지 검수 결과는 [2026-11-19 콘텐츠 방향](CONTENT-DIRECTION-2026-11-19.md)에 기록합니다.

## 시작 문장

```text
이번 주 AI 냠냠 시작
```

이 문장으로 후보 5개를 받은 뒤 다음 순서로 진행합니다.

```text
주제 선택 → 근거·제목·목차 → 목차 승인 → 사용 메모 → 초안
→ 문단별 수정 → 네이버 준비·검수 → 최종본 승인 → "발행" → 링크 갱신
```

예약 실행은 사용하지 않습니다. 주제, 목차, 최종본은 매번 주인장이 승인합니다.

## 파일 원칙

- `brief.md`: 독자 질문, 출처, 제목 후보, 승인된 목차, 주인장 메모를 기록합니다.
- `draft.md`: 네이버에 넣을 최종 원고와 메타데이터만 둡니다.
- `content-index.json`: 상태, 발행 URL, 문제 묶음, 역할, 의미상 다음 글, 최신성, D+7·D+28의 단일 원본입니다.
- `performance-log.csv`: 글별 D+7·D+28 조회·검색 유입·반응·작업시간을 기록합니다.
- 원문 자료 전문, 로그인 정보, 세션 파일, 네이버 DOM은 저장하지 않습니다.

`somsom-master.png`는 확인된 기존 캐릭터 기준 자산입니다. 해시가 달라지면 표지 제작을 멈추고 원본 여부를 다시 확인합니다. `_shared/cover-template.html`은 원본 이미지를 바꾸지 않고 제목만 겹쳐 보여주는 템플릿입니다.

## 안전 게이트

- `[[확인 필요]]`가 남으면 네이버 준비와 발행을 모두 중단합니다.
- 직접 사용 후기는 사용 단계와 경험 메모 네 문장이 있어야 합니다.
- 네이버 편집기 검수 전에는 발행하지 않으며, 최종 승인 뒤에도 정확한 `발행` 명령이 별도로 필요합니다.
- 발행은 현재 대화에서 주인장이 정확히 `발행`이라고 요청한 경우에만 진행합니다.
- 링크 갱신에 실패해도 새 글을 다시 발행하지 않습니다.
- 발행 직전 `publishing`, 결과가 불명확하면 `outcome_uncertain`을 기록해 같은 글의 자동 재발행을 막습니다.
- `proposal`은 비교·검수용일 뿐이며 승인과 실제 목차 URL 없이는 `prepare`를 통과하지 못합니다.
- 발행 기한이 지난 사실·가격·플랜·정책은 다시 확인하기 전까지 `prepare`를 통과하지 못합니다.

4. AI 결과를 덜 어색하게 다듬기: `entry → proof`
