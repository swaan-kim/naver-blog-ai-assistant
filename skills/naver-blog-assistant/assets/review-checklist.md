# 네이버 블로그 발행 전 검수표

- [ ] `brief.md`, `draft.md`, `content-index.json` 패키지 검증이 통과했다.
- [ ] 주제와 목차가 승인됐고, 최종본도 주인장이 명시적으로 승인했다.
- [ ] 제목이 제목 영역에 정확히 한 번 들어갔다.
- [ ] 본문에 제목이 중복되지 않았다.
- [ ] 승인한 목차와 소제목 순서가 일치한다.
- [ ] 소제목 앞 간격과 본문 문단 구분이 눈에 보인다.
- [ ] 문단은 1~3문장이고 표는 최대 1개다.
- [ ] 경험 주장은 주인장의 네 가지 메모에 존재한다.
- [ ] 핵심 주장은 출처, 주인장 경험, 또는 주인장 해석으로 구분되어 있다.
- [ ] 측정하지 않은 수치나 효과를 만들지 않았다.
- [ ] 카테고리와 태그가 정확하고 태그가 중복되지 않았다.
- [ ] 표지 1개, 실제 화면 또는 설명 도식 1개, 목차 링크, CTA가 있다.
- [ ] AI 생성·편집 이미지가 있다면 네이버 `AI 활용` 설정이 켜져 있다.
- [ ] `[[확인 필요]]` 표시가 0개다.
- [ ] 기존 아홉 편과 다른 임시저장 글을 수정하지 않았다.
- [ ] 검수 모드라면 새 편집기에서 멈췄다.
- [ ] 발행했다면 사용자가 현재 글에 정확히 `발행`이라고 요청했고 URL을 확인했다.
- [ ] 새 글 발행 후 목차와 직전 새 글의 링크를 갱신했다.

## 독자에게 실제로 남는 것

- [ ] 첫 문단에 독자가 알아볼 장면, 궁금증, 이 글에서 얻을 답이 있다.
- [ ] `reader_reward`가 본문에서 실제로 전달된다.
- [ ] 구체적인 사례 1개와 과장하지 않는 한계 1개가 있다.
- [ ] 체크리스트·판단 기준·비교·작은 실험 중 다시 쓸 수 있는 도구가 1개 있다.
- [ ] `확인한 자료(기준일)` 또는 자연스러운 본문 링크로 출처가 독자에게 보인다.
- [ ] CTA는 막연한 댓글 요청이 아니라 독자가 바로 해볼 행동 1개다.
- [ ] 다음 링크가 있다면 무엇을 더 얻는지 앵커 문구에서 알 수 있다.

## 레이아웃과 간격

- [ ] 소제목 앞뒤에 빈 문단이 하나씩 있어 이전·다음 내용과 붙어 보이지 않는다.
- [ ] 각 목차 사이의 세로 간격이 충분해 구간을 한눈에 구분할 수 있다.
- [ ] 단계와 목록은 한 단계만 들여쓰기 되어 있다.
- [ ] 세 개 이상의 정보가 이어질 때 줄글 대신 목록, 표 또는 설명 상자를 사용했다.
- [ ] 모바일 화면에서도 제목·본문·표·이미지 사이의 여백이 답답하지 않다.
