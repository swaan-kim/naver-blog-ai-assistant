# 네이버 블로그 발행 전 검수표

- [ ] 로컬 원고 검증 결과가 통과 상태다.
- [ ] 제목이 제목 영역에 정확히 한 번 들어갔다.
- [ ] 본문에 제목이 중복되지 않았다.
- [ ] 계획한 문단과 소제목이 빠짐없이 순서대로 들어갔다.
- [ ] 소제목 앞 간격과 본문 문단 구분이 눈에 보인다.
- [ ] 흐름도·인용구·표 등 핵심 구조가 하나 이상 있다.
- [ ] 직접 확인한 사실과 해석이 구분되어 있다.
- [ ] 측정하지 않은 수치나 효과를 만들지 않았다.
- [ ] 카테고리와 태그가 정확하고 태그가 중복되지 않았다.
- [ ] 기존 게시물과 임시저장 글을 수정하거나 덮어쓰지 않았다.
- [ ] 검수 모드라면 새 편집기 또는 발행 설정 화면에서 멈췄다.
- [ ] 발행했다면 사용자가 현재 작업에서 명시적으로 요청했고 결과 URL을 확인했다.

## 레이아웃과 간격

- [ ] 소제목 앞뒤에 빈 문단이 하나씩 있어 이전·다음 내용과 붙어 보이지 않는다.
- [ ] 각 목차 사이의 세로 간격이 충분해 구간을 한눈에 구분할 수 있다.
- [ ] 단계, 목록, 예시와 보충 설명이 상위 항목보다 한 단계 들여쓰기 되어 있다.
- [ ] 세 개 이상의 정보가 이어질 때 줄글 대신 목록, 표 또는 설명 상자를 사용했다.
- [ ] 모바일 화면에서도 제목·본문·표·이미지 사이의 여백이 답답하지 않다.
